## 🚀 Sektorsprung – Harzi Edition

Mit dem **Sektorsprung-Script – Harzi Edition** wird der Sektorsprung in  
**C&C: Tiberium Alliances** übersichtlich und komfortabel dargestellt.

Das Script unterstützt die Ermittlung und Ausgabe der relevanten Informationen
für einen Sektorsprung und bietet gegenüber der ursprünglichen Version eine
wichtige zusätzliche Funktion:

> 🌍 **Mit aktivierter Checkbox „Weltkarte“ kann direkt zu den ermittelten
> Koordinaten auf der Weltkarte gesprungen werden.**

Damit müssen die Koordinaten nicht mehr nur aus dem Chat abgelesen und anschließend
manuell auf der Weltkarte gesucht werden.

---

## ✨ Funktionen

### 🛰️ Sektorsprung

Das Script unterstützt die Berechnung bzw. Ermittlung der für den Sektorsprung
relevanten Informationen und stellt diese übersichtlich im Spiel dar.

### 🌍 Direkter Sprung zur Weltkarte

Eine der wichtigsten Erweiterungen der Harzi Edition ist die Option:

**☑ Weltkarte**

Wird diese Checkbox aktiviert, werden die ermittelten Koordinaten nicht nur im
Chat ausgegeben.

Stattdessen kann das Script **direkt zur entsprechenden Position auf der
Weltkarte springen**.

### 🆚 Unterschied zur ursprünglichen Version

Bei der älteren Version wurden die ermittelten Koordinaten lediglich im Chat
ausgegeben.

# C&C: Tiberium Alliances – Sektorsprung Harzi Edition

Erweiterte Version des ursprünglichen **Sektorsprung**-Scripts für **Command & Conquer: Tiberium Alliances**.

## Funktionen

- Spieler anhand des Namens suchen
- Voraussichtliche Landepunkte berechnen
- Ausgabe im Allianzchat
- Ausgabe im Offizierschat
- Weltkarte direkt auf den gewählten Landepunkt zentrieren

## Installation

1. Tampermonkey installieren
2. Die aktuelle `.user.js`-Datei herunterladen
3. In Tampermonkey installieren
4. Spiel neu laden
